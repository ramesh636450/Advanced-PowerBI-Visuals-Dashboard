# Advanced Power BI Visuals Dashboard

## Overview
Showcases advanced Power BI capabilities including custom visuals,
complex DAX calculations, and dynamic multi-page report design.

## Features
- Custom visual types: waterfall, scatter, treemap, decomposition tree
- Dynamic DAX measures for time intelligence and ranking
- Multi-page report with cross-filter interactions
- Conditional formatting and dynamic titles

## Tools Used
- Power BI Desktop (DAX, Power Query, custom visuals)

## Purpose
Built to demonstrate advanced BI reporting skills beyond standard dashboards.

## How to Use
Download the .pbix file and open in Power BI Desktop.
