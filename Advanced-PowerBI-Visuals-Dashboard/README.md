# Advanced Power BI Visuals Dashboard

## Project Overview
Developed an advanced Power BI dashboard to analyze sales performance, customer behavior, returns, and profitability using advanced visualizations and business intelligence techniques.

## Tools Used
- Power BI
- DAX
- Power Query
- Data Modeling
- Excel

## Advanced Visuals Used
- Key Influencers
- Decomposition Tree
- Ribbon Chart
- Waterfall Chart
- Funnel Chart
- Map Visualization
- Combo Charts

## Key Analysis Performed
- Sales and profit trend analysis
- Customer funnel analysis
- Return and product category analysis
- Campaign performance analysis
- Country and state-level sales insights

## Business Insights
- Identified factors influencing product returns.
- Evaluated sales and profit performance across regions.
- Analyzed customer funnel stages and campaign effectiveness.
- Visualized return trends and profitability patterns.
